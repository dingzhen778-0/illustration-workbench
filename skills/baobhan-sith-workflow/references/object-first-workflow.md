# 素体绘制法与可控部件契约

## 固定目标，不固定失败路径
保留测量→独立部件→必要绑定→贴合的控制目标。当前经验要求在变形前增加“先配准”，并允许同素体分支＋完整源图蒙版。旧的“每次几何底图、每件必做网格、每张整人必先硬切”的顺序不再默认执行。独立RGBA仍是有效选项，按用户指定任务选择。

## 1. 测量与条件
冻结素体版本、实际画布、H单位、相机、光源和色板。区分人体锚点（如关节中心）、服装锚点（袖根/腕口截面）、轮廓辅助点；记录可见或推定依据。测量当前人体不能证明其本身合理。
需要几何条件时画清目标骨段比例、方向和宽度，作为实际参考图；不只写坐标，也不默认它是编辑底图。标尺可放在空白处，不让它变成角色饰物。三枚不共线标记可检查尺度/方向，但仍需嘴/眼/肩腕等内部位置复核。

## 2. 按部件制作
单次通常约三参考：素体编辑目标＋官设局部＋本次必要辅助（几何或共享色板等）。明确角色/职责，保存真实调用列表，不自行增加生成对象作风格模板。默认保留后端不确定性：提示词不是像素锁定或ControlNet。
- 独立层：直接生成新增部件RGBA，保留源图/画布；不要绕一轮整人后分割。
- 伴素体分支：同一素体各绘制一个区域，保留完整分支，组装时以可编辑蒙版显示目标与局部过渡。不要直接叠整人，也不默认删掉RGB做硬切。
上述输出按用户要求选择；不能因一次独立生成失败就否定整个路线。用户明确指定底图时遵从，不以流程模板替代。
双袖优先同源成套生成、分远近层控制；衣身、立领、颈褶、白襟、灰领巾、蝴蝶结按具体组件制作，不能整套生成后拆层充数。头发先前/中/后三套纯色模板，合成几何后统一绘制基础体面，最后集中完善色光；不默认逐束独立渲染。独立分支可并行，但依赖阶段不得并行跳过前一步。共享色板是目标，输出颜色仍须核对。

## 3. 先配准
脸与眼睛是本项目明确的依赖阶段：先在头部素体画肤色和体面，以上色脸部素体单独画眼睛，再各自配准、蒙版贴合；不得并行跳过上色脸部基准。详见[脸眼素体绘制](../../rendering-polish-baobhan-sith/references/face-eye-sutai.md)。

记录实际尺寸、裁切、留白和局部到全局变换。同画布不等于同位置；先区分整体平移、统一尺度/旋转与局部形变。嘴部可定平移，有第二个可靠内部特征才能检查其他关系。
外部标记估计相似变换后，再看人体内部残差；不能用标记原位推出人体没有重绘。只有实际对应点支持时才缩放/旋转，避免用不透明像素最近点代替语义对应。

## 4. 按需网格
整体平移不需网格。明确有局部小幅包裹/姿态调整需求时，按生成资产自身轮廓与alpha建网格，再用已核查关节/截面控制。保存源图和控制点，每次从源重新计算。
几何默认隐藏，不用长条补底遮错位；手等前景保留独立遮挡。若需剧烈压缩、密集针点拉出凹口或改人体才能套合，回到版型/生成/锚点。变形不自动重算褶皱、投影或高光。

## 5. 蒙版组合
完整分支作智能对象，部件核心清楚、外围有限淡出，保留源图可回退。保护相邻实体、肤面和前景手；只有接合处柔化，不将整层半透明。软带可能混入分支中的人体像素，须明确实际范围。
后发在人/服装后，侧发按具体遮挡，前发在脸前；可见分量不等于完整隐藏面。拼接细节读[配准与完整源图蒙版](../../rendering-polish-baobhan-sith/references/sutai-registration-compositing.md)。

## 6. 原生完善与验证
大暗面、色值、高光、软硬边和发梢色彩优先用当前原生图层/蒙版/笔触做明确变量；需要新结构才局部生成。手动方法可控但不自动具有更高审美，亮带串珠化/等距化、暗面条带化需纠正，不能用“手操完成”当画法已掌握。
base/detail/mask/lighting按实际能力记录。生成合并光影标baked_lighting，生成后按颜色拆层标功能分层，直接原生绘制标native_manual。投影归接收表面；结构/遮挡变化后检查光影是否过期。
保留纯色、细化、修正关闭状态；软/硬边用同样源图和绘画内容。差分0仅证明边界/回退，不证明服饰或光影正确。记录measurement、actual_inputs、output_mode、source、registration、mask、optional_binding、lighting、technical_check、visual_review和user_acceptance。
PSD未保留实时控制时交付源图/外部变换，不宣称有实时骨架。画师PSD/教程研究按真实来源和已观看范围记录；Live2D是按需工具，不作为绘画前提。


## 同款双袖：共享设计，独立控制
成对同款部件的生成范围与交付层级分开：本项目双袖优先在同一素体上一次联合生成，以共同决定袖山、收束、褶皱语言与色光；随后同源复制为远/近袖两个可独立控制的蒙版图层，置于共享组。联合生成不等于合并交付，也不要求两袖镜像。用户明确要求分别生成时仍按两次独立调用执行、共享同一参考与说明。
依据：2026-10-19同素体联合生成与同三参考的两次独立生成对照，用户明确评价联合组更好。这是本项目的方案选择，不能扩展为所有成对对象都必然联合更好；相同参考也不保证独立生成的版型/色值一致。保留输入、两类对照和获选来源，组装时分别检查远近袖透视、袖山体积、单尖腕口和手部遮挡。
