# 巴万希可控分层插画

## 当前主链
固定素体与测量 → 按部件制作 → 先配准 → 按需网格 → 蒙版组装 → 原生绘制/局部完善 → 分开验收画面与技术。
遵循[共用执行契约](references/object-first-workflow.md)。测量与独立对象仍保留；几何图不是默认编辑底图，网格不是每次必须执行的步骤。

1. 冻结画布、素体、视角、光源、色板与可见/推定锚点。本项目的人体素体须完整无发、无衣饰，保留完整颅顶/额颞/耳/下颌/颈肩；头发和服装只能作为后续独立分支。带旧发/衣服的大色块候选不能冒充可复用人体素体。保留未覆盖的原图与哈希，需要时另加可关闭的标尺/定位层。
2. 以素体提供空间关系，官设提供身份/版型。单次通常约三图，第三图按需要选择色板或几何条件；不自行追加竞争姿态的生成对象作画风模板。每张职责及实际提交路径须保存。
3. 按用户选择输出完整独立RGBA，或复制同素体、各分支绘制指定部件或需保持同款关系的成对部件。后一种“素体绘制法”保留完整分支源图，通过可编辑蒙版组合，不默认先硬切掉其他像素。本肩像后发返工须回到原始无发无衣灰色素体，几何在其后，由头耳颈肩遮挡；完成稿只作拼装目标，不能擅自替换编辑底图。两种交付均不能仅凭同画布宣称同坐标准确。
4. 本项目双袖优先同素体联合生成，再分别蒙版控制并放共享组；用户明确要两次独立生成时遵从。独立部件可并行；胸腰红衣主体→以穿红衣版本追加前襟是依赖阶段。头发采用前/中/后三套独立纯色几何模板，同组两侧联合设计；合成完整发型后统一生成低细节基础体面，再集中组织高光、暗面和发梢色彩。几何分层、生成范围与交付层级分别记录，不再默认逐束独立渲染。服装按衣身、双袖、立领、颈褶、白襟、灰领巾、蝴蝶结等具体组件各自从模板生成；整套衣服一次生成后分蒙版不满足此要求。细则见[头发造型](../rendering-polish-baobhan-sith/references/hair-native-shaping.md)。
5. 先用嘴部等稳定内部特征配准；有足够对应点时再解缩放/旋转。外部标尺与内部人物位置分开检查。标尺不动不等于人物未漂移，一个点也不能证明整幅重合。
6. 残余小幅包裹/接缝偏差才进入对象自身网格。关节、服装截面和轮廓点分别定义，不强拉长前臂、错袖型或错误遮挡来凑合。
7. 完整源图用局部蒙版显示核心及必要渐隐，保护相邻部件实体；轮廓和层序仍需明确。色彩/光影变量优先在原生层操作，生成重建只解决明确的新结构/内容需求。

## 开始与恢复
先读项目AGENTS、当前状态和最近验收索引，从当前版本继续，不批量重载历史图片。用户指定项目优先，否则使用工作区project_baobhan_sith/。没有完整brief时从会话建立最小记录，不重跑无关研究。
全局素体/场景/基础色块与光源先确定；整图候选仅作构图参考，不等于已获得可编辑对象或通过结构验收。

## 验收与返工
本项目脸部必须执行“素体画脸部肤色与体面→以上色脸部素体另画眼睛→分别配准、蒙版贴合”，保留独立脸部与眼睛控制；执行细则及脸眼清晰度验收见[脸与眼睛两阶段](../rendering-polish-baobhan-sith/references/face-eye-sutai.md)。肩像已跑通两阶段实绘与图层开关验证，不以技术通过宣称乱码或角色神情已经全部解决。

先审服饰语义/大形 → 比例和空间 → 色光与材质 → 接缝，再做技术验证。美术判断、操作验证、用户确认分别记录。只有实际确认才写user-approved。
关闭修正应恢复其基准；软蒙版混入周围源图时说明实际影响范围，不声称全人体未变。比较硬/软边时保持源图、配准、核心不透明度和绘画内容一致，变化像素数不是审美提升分数。
身份/版型错误回A，人体/结构问题回B；整体漂移先配准，形变需求再网格，光影只改目标层。共享色板并不锁定生成色值，按材质与受光角色检查，不把全图颜色中位数当底色。
同一缺陷连续两次无改善时保留最佳版并改策略，不无限加参考/生图。PSD可能仅有当前贴合快照；只有重开确认实时控制仍在才宣称可拖动，其他情况保存源图/控制点与可重算过程。Live2D迁移按用户需求，不替代当前PSD任务。
最终交付预览、真实分层源文件、输入/变换/图层记录与剩余问题；教程和工具能力只按实际核验范围描述。
