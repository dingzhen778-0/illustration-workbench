# 从视觉候选进入可编辑绘画

新画/整体重建的阶段顺序以[全局基础→对象→光影](../../baobhan-sith-workflow/references/object-first-workflow.md)为准；下面的局部变量验证不能替代完整对象与全局基础。

候选图的作用是探索视觉设计。它的细节丰富程度不能替代结构验收，禁止直接把生成图标成可交接结构稿。

## 必需交接
1. 选定图像与相机／姿态说明；原图固定版本。
2. 可见人体与服饰的结构分析，区分观察与遮挡下推定；不是只提取边缘。
3. 对本次要修的部分建立可编辑结构、轮廓／线稿、底色、遮罩和独立光影；不要求在一次局部实验中重建全身，但须标明实际范围。
4. 每层标为 retained-raster、reconstructed、analysis-proxy 或 generated-candidate。将整图复制成五层不算完成拆解。
5. 控制表列出 Skill、目标图层／参数、允许变化、保护范围、检查方式与实际结果。
6. 做一次只改一个视觉变量的试验，交付前／后／隐藏目标层；无局部修改验证，不以提示词里出现“改善光影”计为技能完成。

## 变量职责
人体：姿态／比例／关节／重心；服装：连接／层次／褶向；色彩：明度组／色相／饱和度面积；光影：形体受光／交界／投影；边缘：软硬／虚实；细节：密度／重复／装饰逻辑。
每项都需要实际后端与被修改对象。没有对应已验证技能时标缺口，不虚构能力。painting-value-lighting 当前只覆盖可编辑明度与光影对象，不自动解决其他五项。

现有扁平稿可以作为参考层或受限保留像素；不能因此标记整个B通过。后端缺少层、路径或遮罩编辑能力时，停在候选／分析阶段并交代限制。完整插画的结构检查与用户选稿分别记录。
