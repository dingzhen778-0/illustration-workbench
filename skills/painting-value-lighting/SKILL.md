# 明度与光影控制

## 输入契约
需要原图、可编辑源文件、目标图层／形体、保护区域、光向和明度目标。记录坐标系、文件哈希与待改参数。没有有效形体层或遮罩时，先重建最小目标部分；不能宣称已经接管原图的光影。

新画使用 [全局基础与对象光影契约](../baobhan-sith-workflow/references/object-first-workflow.md)：先在素体/场景建立光源与明暗二分；对象底层及结构细节形成后，再据同一基础细化光影。此Skill同时服务两个阶段，不在对象生成中各自改定主光。对象或光源变更后重新检查相关光影。

## 本 Skill 控制的变量
- 受光面／背光面分界：实际路径或遮罩，不是纹理词。
- 明度分组：亮／中／暗大形的色值、面积和相邻关系。
- 投影：形状、方向、落点、透明度和边缘；只在已知空间关系内修改。
- 投影归属：记录caster与receiver，遮罩属于接收表面；胸部肤面阴影不归衣服对象，发丝投到脸上的影不归头发固有色。
- 视觉焦点：背景与人物的明度差、亮部面积；不能只加轮廓光就宣称形体成立。

## 执行
1. 先判定可编辑对象是几何重建、像素保留、分析代理还是完整绘画层。分析人体线与粗遮罩不算人体重建完成。
2. 写出本次只改的变量、被锁定的内容和可观察的成功标准。例如，只换王座受光侧，保护人物面部与衣服核心像素。
3. 在当前编辑器实际改命名图层。SVG 可改路径、fill、opacity；对单个属性的可靠写入可使用 scripts/edit_svg_attribute.py。只有生成工具时可先提取候选，但须返回可编辑中间结构再验收；缺少这样的后端时报告能力缺口。
4. 至少导出修改前、修改后、隐藏目标层三个状态。复查形体是否因亮暗变化而更可读、投影是否与支撑关系一致；参数变化不等于绘画正确。
5. 用目标／保护遮罩做像素差分；记录实际变动范围。比较色彩配置、渲染尺寸一致的图，不把重采样误差当成编辑。检查失败时修遮罩、几何或编辑方法，不能以新提示词替代验证。
6. 交付源文件、图层表、参数变更、预览和局限。光向仅对王座成立时不得宣称整个人物已重打光；新形体很粗或分割失败时保持实验状态。

同一源文件的不同参数可证明控制性，不能单独证明审美或专业绘画能力。需要用户观看并评价形体与主次。没有渲染／编辑器验证时如实记录未验证部分。

## 真实 PSD 的保细节修正
当现有层的形体明暗已可用，而问题是环境色或局部受光时，优先试剪贴的曲线／颜色调整层，保留原像素。将环境色与定向提亮分别控制，继承原父组蒙版；同时看全图焦点和局部形体，颜色变化更明显不代表更协调。

操作与已测案例见 [真实 PSD 局部光色整合](references/psd-local-colour-case.md)。其中含图层定位、剪贴曲线、局部羽化选区和 PSD 重开验证。仅将其中验证过的光色操作迁移；曲线数值、光向和风格需根据新图重新确定。


## 头发及生成组件的原生变量修正
形状已经可用时，用填充/曲线/渐变蒙版/少量笔触控制大暗面、亮形、局部色彩和边缘，减少重复生成编辑。头发方法及已测边界见[纯色组件到可控光影](../rendering-polish-baobhan-sith/references/hair-native-shaping.md)。新结构才回生成；手动操作不天然优于模型细化。
将绘画范围和拼接过渡范围分开：笔触可严格受头发核心约束，完整源图的外围柔边则可能混入其他像素。分别报告，不能拿前者的范围外0替整个合成声称全人体未变。保留同源硬/软蒙版对照和关闭手动层状态，绘画效果与可控性分开评价。
