# 真实 PSD：保留形体的局部光色整合

## 来源与目标
- 作者：Matt Kohr / Ctrl+Paint。
- 公开教学页：https://www.ctrlpaint.com/videos/layer-groups-adjustments
- 下载：https://www.ctrlpaint.com/s/CtrlPaint-layer-group-worksheet.psd
- 文件：CtrlPaint-layer-group-worksheet.psd，2000×1042，8-bit RGB。
- 本案例使用教学工程中的灰球，不把练习对象说成作者成稿的错误，也不外推成商业二次元角色修图已通过。
- 原图层 Layer 19，原导入 ID 4，bounds [929,493,217,217]（xywh），位于带蒙版的 Group 1 中。

## 诊断 → 操作 → 判断
灰球已经具有可读的球体渐变，但相对洞窟缺少环境色关系。保留其形体明暗，用剪贴到原球体的 RGB 曲线调整环境色，再用带羽化遮罩的第二张剪贴曲线提高朝向洞口的区域。

第一版青绿偏强；观看局部和全图后，收敛红绿蓝通道的分离幅度。这个返修比“饱和度越低越好”更有用：以相邻环境的色彩关系为依据，避免把原来的灰物体变成突出的青色物体。

本次视觉判断：最终版的暗部更接近洞窟绿灰关系，朝洞口侧略亮，原球体渐变及轮廓保留。用户尚未评价审美结果。没有验证投影、材质改造或人物结构。

## 可复用决策
- 原有形体和细节可用、问题主要是色光关系时，先试原生调整层，避免为调色重新生成细节。
- 将环境色与定向提亮分层，分别开关比较；过饱和时先调整通道或强度，不叠加更多纹理。
- 用目标层的剪贴关系限定作用对象；父组蒙版限定遮挡。新遮罩不能代替原有遮挡关系。
- 显示前后、只做环境色、全部调整、关闭调整四种状态。全图检查焦点，局部检查形体和边缘。

## 实际后端操作：PhotoCraft 0.8.2
先 info 读取当前图层树，按名称、bounds 和隐藏效果定位目标；不要把本例 ID 用到别的文件。每次重开后重新读取 ID。

1. layer.select 选择目标。
2. layer.newAdjustmentLayer.curves，新建环境色曲线；layer.setProps 设置 name=CASE_01_environment_colour、clipped=true。
3. 选择该调整层，select.rect 创建椭圆选区：x=1038,y=476,width=157,height=146,ellipse=true,feather=28。
4. layer.newAdjustmentLayer.curves 新建第二张曲线；layer.setProps 设置 name=CASE_02_opening_facing_light、clipped=true、opacity=0.70；select.deselect。
5. 保存新 PSD，重开导出。检查两张新层仍为 Adjustment、clipped=true 且保留 mask。

环境色曲线：
```json
{"red":[[0,12],[60,40],[90,68],[120,101],[170,160],[255,235]],"green":[[0,24],[60,48],[90,76],[120,111],[170,177],[255,244]],"blue":[[0,22],[60,43],[90,66],[120,98],[170,165],[255,239]]}
```
洞口侧提亮曲线：
```json
{"points":[[0,0],[48,48],[85,106],[145,166],[220,226],[255,255]]}
```
参数只适用于本例的像素和光色，迁移时重新判断。

## 已测证据
原文件保留；17 个图层节点（含组）变为19个。修改37,018像素；217×217目标边界框外0变化。关闭两张新层后，与同一后端的修改前导出逐像素一致；未修改的 PSD 往返导出差异为0。扩散调用0次。

隐藏目标层得到的“可见影响区”只是差分代理：它与最终改动有1个像素、1级通道值的出入，不能把它当精确 alpha。严格保护检查应读取真实 alpha／蒙版或报告边界误差。

只有同后端的往返与开关检查时，将证据表述为该后端验证；不能据此保证 Photoshop 等其他编辑器表现完全相同。

独立复核：psd-tools读取确认原像素层RGBA与原组蒙版未变，实际改动在原目标alpha内，alpha外0变化。原保存合成与后端重绘仅378个像素有1级舍入差异。psd-tools对新增曲线扩展字段有CurvesExtraMarker读取警告；本例的曲线重开验证限于PhotoCraft，不外推Photoshop兼容性。
