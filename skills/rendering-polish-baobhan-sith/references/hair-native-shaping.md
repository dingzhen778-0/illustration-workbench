# 头发：纯色组件到可控光影

## 先结构，后画法
### 本项目最新路径：几何分组、统一绘制、集中完善
用户比较后纠正了逐束独立渲染的路径：独立交付可行不等于每束各自设计能得到统一发型。前/中/后按几何与遮挡分三组，各自生成纯色模板；同一组的左右联合设计，不按左右拆成竞争风格的独立请求。

1. 冻结完整无发人体，依据官设建立三组模板与完整几何上下文。模板只确定轮廓、流向、主束边界、内侧面及必要隐藏重叠，不画高光、渐变与碎发纹理。分别保留实际源图和配准记录；严格纯色需要时按目标范围重建原生填充，并说明重建事实。
2. 三组叠合后检查整头体积和发根连接；以该完整几何模板引导一次统一基础绘制，只画干净线条与基础体面。生成范围是完整头发，控制范围仍由三套模板提供。不能把模板重新解释成逐束各自完成高光。
3. 在整头基础上集中处理高光弧势、暗面和发梢色彩，最后用前/中/后蒙版提供控制。可用原生绘制或一次统一模型完善；生成的明暗仍属baked_lighting。规则矩形切口的几何亮带若不自然，应淘汰，不以可编辑为审美通过。
4. 统一渲染源按组蒙版显示时，写清是同源功能区域，保留独立纯色模板与整头渲染原图；不能声称恢复模型内部画师图层。模板的完整隐藏面与渲染中的可见面分别记录。

2026-10-20实测：3次独立纯色模板→1次整头低细节基础→1次整头集中完善，另有7次服装组件生成。旧九束独立质地路线保留为失败对照，不再作为当前强制规则。手工规则亮带本次被淘汰；成图保留基础/完善两阶段及原生少量调色。是否更自然以全图和局部检查判断，不由调用数/配准残差决定。

服装对应原则：生成范围遵循具体组件。成套双袖联合生成后可分远近控制；衣身、立领、颈褶、胸前白褶襟、灰领巾、蝴蝶结分别从几何伴人体模板生成。人体配准后仍要复核组件本身大小：本次领巾与蝴蝶结在人体稳定时仍膨胀，需按模板局部仿射贴合。保留贴合前源图/变换，不把局部尺寸校正称为骨骼绑定。

边缘处理：alpha余量与有效RGB延展分别检查，不能把灰人体/背景带进发束；暗线不应统一当灰边抹掉。白褶襟的灰色折面仍是不透明布料，不能按颜色删成漏肤孔。原单束验证与九束失败的详细旧规归档于本轮outputs/.../skills-before/，不作为当前执行命令。

前发/冠部、侧发、后发分别拥有大形、连接和遮挡。纯色阶段先检查发根是否接上、侧发是否沿头部/肩部转向、长束是否连续；用细线或漂亮高光遮住断束不算通过。
生成并不保证真正纯色；需要严格底色时以对象范围建立原生单色层，原生成参考另存。只覆盖可见区域时明确隐藏表面尚未补全。

## 手动处理优先的视觉变量
### 后发局部返工的结构闸门
本项目长发后组须先建立后脑/后颈的发量连接；不能把两侧贴脸卷片改名为后发。分别检查完整对象和人物遮挡后的预览：完整对象可保留推定隐藏面，合成时头、耳、颈肩和衣服实际挡在前面。不要为了展示隐藏对象，给模型一个后发盖在脸前的错误编辑底图。此要求不等于所有发型后组都必须是一片连续外壳，按真实分缝/束源决定。

v4返工已被用户否定：移除人物视角参照、要求“圆顶/填实中心/后发外壳”后，实际得到的是背面发型。后续仅换二次元材质并不能修正相机错误；不能再把它记作结构通过。后发的“后”是相对于当前人物的遮挡层次，不是背面观察视角。不得把几何底形本身当作已经验收的答案。

本肩像后发返工采用原始无发、无衣灰色肩像素体作为编辑底图，后发几何位于头、耳、颈肩后方，由素体实际遮挡；完成稿仅是后续拼装目标，不替代素体输入。保留同一相机与姿态不等于允许换成完成稿。官设长束局部提供画法，生成后保留完整“素体＋后发”源图，配准稳定灰色脸耳特征，再将后发可见区以原生蒙版回贴到肤面/衣服/前中发后面。只生成可见区域时说明隐藏面未绘制纹理。不要另造背面发型塞入当前图。v5完成稿编辑路径已因不遵守用户素体要求撤回；v6为素体路径实测，技术检查通过不等于后发轮廓已获审美验收。

后发替换时还要隔离旧的全局调色蒙版，避免删除后发后仍在空处留下色带。前景保留范围应从实际对象组合求得，不能把全局填充/调色层自身alpha当作前景几何。记录未重绘与像素差异的区别，不能用关新后发恢复基准diff0代替全前景完全不变证明。

在形状已可用时，先用原生填充、曲线、渐变蒙版和少量笔触控制下列变量，再决定是否需要生成重建：
1. 大束分面：少量连续的受光/背光面解释曲率，不沿每条线均匀描暗。
2. 深紫内侧：拱起发根、遮挡接缝和束的背面使用局部大暗形；不能将同一长条紫色铺遍所有发束。
3. 刘海弧带：亮形沿头部圆面组织，再被发束边界分断；宽度、方向、间隔随曲面和束面改变。不是完整白圆，也不是串珠或等距亮条。少量中间连接可让弧带连贯，但不涂满整头。
4. 侧发亮面：沿长束走向收尖，在转折/遮挡处分断，避免复制刘海横条。
5. 发梢色彩：灰粉紫只影响指定区域，保持受光/暗面层次；仅按画布高度统一渐变是可控试验，不等于已经解释各束受光。

## 图层与操作
可采用基础色、结构线、大暗面、亮形、发梢色彩等分工，按实际需要增减。使用对象遮罩限定范围；遮罩外的脸部投影另归脸/接收表面。保留原图；每项可独立关闭。
PhotoCraft已试过原生带蒙版纯色填充、手定曲线形状、渐变范围及paint.stroke。曲线/笔触是执行手段，形状必须来自本图发束和光向，不能复制某个案例坐标后声称掌握画法。
需要模型补新结构时一次只处理一个组件/明确缺陷，保留版型与配准参照；不要为了每项高光/色彩连续重采样整张图。已有好看细节优先保留，手动并不天然优于模型渲染。

## 验收
先看体积与主次，再看开关/范围差分。至少导出纯色、细化、关闭高光三个状态，核对高光是否沿圆面、暗面是否连续、颜色是否共享、边缘是否脏。生成结果按颜色/明度拆成的功能层不是模型内部作画层；直接手动建立的层才标为native_manual。
2026-10案例已证明9项手动层能改画面且不越过头发核心范围，但亮带仍偏规律、暗面仍像平贴条带；手动版在自然度上尚未证明超过分组件生成细化版。记录为操作验证，不作为成熟官设画法模板。

## 头顶弧带：先整体，再顺束削形（教程支持，当前PSD待试）
适用：已有可靠发束大形，需修复逐块添加造成的串珠、等距亮条；不负责修复断束或发根结构。

1. 先标光向、头部圆面和几条主发束的流向；在独立高光层画一条连贯弧带作为底形。45度视角按头部曲率设计可见弧段，不画绕满头的正圆。弧带横跨发流；削形笔触沿发流，两个方向职责不同。
2. 用头发对象范围限制高光，另加可编辑削形蒙版。白色可作为初始底形，红发优先试浅粉/带环境色的亮色。Normal白色降透明度能混入底色；Screen纯白仍是白，不能仅换模式便假定自然。
3. 在蒙版上从亮带上下缘沿各束流向削入。先处理大束边界和背光/遮挡处，再用少量长短、粗细、深浅不同的条状削痕整理边缘；保留不等宽亮片和部分连贯弧势，不随机均匀撒细条，也不把每束切成孤立等大的珠子。
4. 形状可读后再调层不透明度、色相及必要的局部柔化；透明度可在削形前暂调便于观察，但不作为固定数值或必须的先后。只局部柔化，保留受光面的清楚边缘。最后少量补最亮点，远侧/转面减弱或中断，按同一光向核对。
5. 导出旧高光、完整弧带底形、削形调色后、关闭新高光四状态。缩略图检查弧势与焦点，100%检查削痕是否对应发束、轮廓及遮挡；图层开关/范围差分单独验证。效果未经当前PSD对照前只记待试画法。

建议控制：高光源层（颜色/不透明度）＋削形蒙版（发束节奏）＋对象范围（不越界）；保留未削底形或其隐藏备份。将用户的“条状橡皮”落实为可恢复蒙版，不必删除底色或重新生成整头。
