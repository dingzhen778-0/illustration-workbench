# 历史实验：穿衣预览后硬切回叠

以下保留早期试验的实际做法与证据，不是当前优先路线。现在按用户任务选择独立RGBA或完整素体分支；伴素体分支可保留完整RGB并使用可编辑局部渐隐蒙版，操作见[当前配准与组装](sutai-registration-compositing.md)。不默认先删掉外围像素，也不强制几何编辑底图。

# 素体条件生成与对象回叠

## 何时使用
为已有素体制作服装等依附对象，独立透明素材反复出现相机、尺寸、位置或遮挡漂移时使用。目标是保留原素体并获得能单独编辑的对象，而非让生成模型重新决定人体。

## 素体与结构锚点
准备不含文字的干净素体和可关闭的辅助标定层。锚点表达解剖结构与连接关系：前后颈根、可见肩峰、胸骨/锁骨参考、可见肩胛参考；头部可用颅顶、耳根、发际和下颌。按视角选择，遮挡骨点标推定，不凭轮廓点名称声称骨骼定位准确。保存画布、坐标系、素体版本、点的像素/归一坐标、证据和头高等比例单位。先检查这些点组成的颈柱、肩带、胸腔关系；标尺不自动验证人体合理性。

## 经过本项目试验的路径
1. 给生成后端完整素体作为实际编辑目标，服装官设只作设计参考；请求在同一画面给该素体穿衣。保持相机、朝向、取景与人体比例；头＋衣、头＋发分别制作中间品。
2. 先审穿衣预览的颈部包裹、肩点、胸腔轮廓及视角。辅助锚点可帮助表达意图，但文字坐标不是硬控制。当前内置后端输入参考图不等于已有ControlNet或精确区域蒙版。
3. 只提取预览中可见服装及其透明遮罩，排除生成的肤面、头部和背景；保留原始预览。可用编辑器选择、语义分割后人工检查或人工轮廓。接缝处不得把皮肤/皮肤阴影当衣服；检查领口内缘、蝴蝶结尾端、肩洞、袖口和半透明边。颜色阈值只作辅助，不能代替对象归属。
4. 将衣服按原画布坐标、原尺寸放回原始素体PSD的独立层。丢弃生成时重画的身体，先不缩放或变形。只有画布分辨率整体改变时才同步等比换算对象和锚点，不单独重居中。该层是从生成预览提取的可见对象，不是恢复模型原始图层。
5. 检查回叠的锚点、包裹轮廓、穿插和裸肤开口。预览协调而回叠失配，说明模型改了素体或对象轮廓，不能用移动身体或分别压扁宽高掩盖。局部误差在对象层/蒙版上修；整体姿态错则回到生成约束。
6. 关闭对象层应恢复原素体；同时检查对象非零alpha范围外像素未变。技术检查、用户对可行性的确认、结构边界验收分别记录。生成中已合并褶皱阴影的对象标baked_lighting=true，后续再重建底色/细节/光影，不能称纯底色已完成。

## 实验范围与失败分支
2026-10-18巴万希一破左侧头像试验：第一次“看锚点素体但只输出透明衣服”仍被模型重新居中并生成近正面双袖，失败；第二次“给素体穿衣→提取可见衣服→回叠原素体”获得用户可行性认可。1086×1448画布，对象未缩放/变形，原生PSD重开，关闭对象恢复原素体差异0。提取边缘仍待精修，服装自带合并光影。头发及其他姿态尚未用这条路径验证。

若有已可用的选区/姿态/线稿/深度控制，可约束生成范围与几何；这属于后端能力，不靠在提示词里写其名称获得。本案例未部署或测试社区插件。
