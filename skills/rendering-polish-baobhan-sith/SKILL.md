# C：上色、修正与交付

## 主流程：素体分支/独立对象 → 配准 → 按需网格 → 蒙版与原生完善

读取[共用契约](../baobhan-sith-workflow/references/object-first-workflow.md)。素体提供空间与姿态，官设提供版型，辅助图按几何/色板需求选择，通常单次约三图。不要默认几何图是编辑底图或每个对象都必须网格变形。
按用户指定直接输出独立RGBA，或同素体分支各绘制一个组件。完整分支优先保留原RGB，以智能对象＋可编辑局部蒙版拼接，不默认硬切；先配准，再对明确残余形变作小幅网格调整。
拼接读[配准与完整源图蒙版](references/sutai-registration-compositing.md)；头发由纯色形状到暗面/弧带/发梢色彩读[原生头发造型](references/hair-native-shaping.md)；实际变形才读[绑定操作](references/geometry-bound-assets.md)。颜色、光影、边缘等明确变量优先原生修正，不连续整图重采样。手动绘制仍须审美验收。

输入：brief、A 的固定特征与配色、B 的选稿／结构稿与验收。遵循 `../baobhan-sith-workflow/references/handoff.md`。确认当前输入未过期；用户直接给定可用线稿时可检查后将其登记为 B 的输入成果，不强制重新起稿。

单独调用时先定位用户项目与已有 brief；缺少完整档案时从用户已给图片和约束补最小记录。仅修现有图像时不强制重跑无关阶段，但要检查本次修改依赖的身份／结构输入。

## 执行

1. 读图并记录不可变项：角色身份、服装版本、构图、姿势、画布与关键轮廓。拆分本次允许调整的颜色、光向、材质和细节。
2. 在已有可编辑层上做指定局部控制时，优先使用该源文件的绘画／矢量编辑后端并验证实际变量；需要生成候选或图像语义编辑时再使用已可用的 imagegen Skill 和当前原生生成／编辑工具；本地目标图先查看，再作为编辑输入。把身份参考、编辑目标、风格／光影辅助图分别标记。透明素材要请求真正透明底，保留 alpha。
3. 先确立固有色与大光影，再细化手、发饰、布料等焦点。本项目脸部须分为“素体画脸部肤色与体面→在该脸部素体上另画眼睛→分别配准与蒙版贴合”，执行时读[脸与眼睛两阶段](references/face-eye-sutai.md)，不再将全部肤面五官一次生成作为默认完成路径。其他对象按任务需要分步。每次调用前写 prompts；每个候选存 revisions，不覆盖获选版本。
4. 局部问题从最新合格版本编辑，只提出本次明确变更与保留项。有实际遮罩能力时使用遮罩；没有时只能语义限制，不能承诺区域外像素完全不变。出图后同时检查修正区与非修正区的身份／结构漂移。
5. 已安装且用户选择 ComfyUI 时使用其现有工作流与实际可用节点；不自动下载模型、安装节点或改变全局工具路由来填补能力缺口。

## 分层与源文件

用户只要完成图时直接交付完成图，不为流程形式强制生成多层。用户需要分层时先确认交付层级：独立素材还是线稿／固有色／阴影等绘画层。

- 可以从生成起分别保存背景、角色、饰物和遮罩，并记录尺寸、位置和层序。若需要组装 PSD，按需读 [分层后端](references/layered-output.md)。
- 仅有扁平图时不能恢复原作者真实绘画图层；遮挡补全是推断。若生成独立素材可满足用户目标，如实标记为素材层。
- 只有实际支持的编辑器／后端才可交付含相应混合模式的绘画源文件；无法满足指定源文件能力时标明未完成项，不把 PNG 改名为 PSD。

## 验收

按 A 逐项核对身份与服饰，按 B 检查构图／结构，再看脸手、边缘、光源、材质、背景主次、意外文字和透明边。保存 revision.json 中的输入、请求修改、实际变化与残余问题。

局部色彩／材质问题留 C；结构问题回 B；身份与设定冲突回 A。连续两次修复无改善时保留最好结果并说明瓶颈。

final/ 只放获选成果及 delivery.md。实际打开最终图检查尺寸／画面；有源文件时检查层数、名称、层序、透明与合成预览，能控制编辑器时重开确认，不能时明确验证范围。最终展示图像和绝对路径、所用后端与提示词位置，不把未试验能力写成已验证。


## 可编辑控制闸门

进入结构修正／完善前读 [视觉变量与中间结构契约](references/visual-control.md)。生成候选不能直接作为通过验收的结构稿。对本次目标建立真实可编辑层并完成一次局部变量试验；涉及光影时可用 painting-value-lighting，但须检查其工具与目标文件是否实际可用。

## 先鉴赏，再定位修改对象
当前对象仍混在扁平底图里时，先建立语义对象范围及可编辑控制，再局部修改。可保留完整源图并用蒙版显示；只有确需独立像素对象时才提取，不能默认删除外围RGB。肤面、布料与多余饰物按语义分别归属；颜色相近或阴影连在一起不能作为同一对象的依据。提取后重合应恢复原图；从工作底图挖去提取区域，隐藏对象时不应露出重复的底图内容。保留原文件或隐藏归档组。只提取可见像素时说明遮挡部分尚未补全，不把复制一块矩形称为对象拆分。

对现有分层图先写一条可检验的“现象 → 画面关系 → 目标图层 → 操作”：例如灰色对象脱离环境，可先在原对象上用剪贴曲线调整环境色，再用局部遮罩改变受光强度。不能只凭图层名推断功能，应通过开关确认其视觉作用。

原有形体与细节有效时，优先调整层、蒙版或变换；需要新结构／内容时才局部生成。光色操作可参考 painting-value-lighting 的真实 PSD 案例。审阅时同时比较修改前、单项调整与全部调整，避免把更艳、更亮、更细误当作改善。

荷叶边出现孤立灰三角、折线与轮廓不相接时，读 [单折重建](references/frill-fold-repair.md)，先确定缝合边、自由边和返折关系，再决定阴影形。此案例仅验证小范围蒙版与图层控制，不能直接推广为完整衣服结构已解决。

版本替换后重新验证目标层是否仍影响当前画面：上方生成替换层可能覆盖旧修正；对象轮廓改变后重建遮罩，不沿用旧对象范围。关闭目标层必须能产生本次预期变化。

可并行制作受同一光向、明度主次和配色约束的独立部分，合成后再统一检查。案例的操作验证与审美评价分别记录；未检查的结构、材质或风格效果不写成已掌握能力。

## 依附素体的完整对象
本肩像后发返工必须以原始无发无衣灰色肩像为编辑底图，后发几何在头耳颈肩之后；完成稿只用于后续拼装。保持同相机不能代替这个输入要求。先保留可核查的“原素体＋后发”分支，再配准回贴，禁止直接拿完成图重绘后宣称素体绘制法。
本项目头发按前/中/后分别制作纯色几何模板，再用合成模板统一绘制整头基础体面，最后集中完善色光。同组两侧保持成套设计；不默认每束各自渲染。完整渲染按前中后蒙版控制时如实标为同源功能区域，不冒称独立生成或原始画师层。服装按具体组件独立生成源图；双袖可成套生成、独立交付。执行前读[几何分组与统一绘制](references/hair-native-shaping.md)。
新服装/发束遵循共用契约。两袖、裙体、饰边、蝴蝶结分别控制；本项目双袖优先同素体联合生成后分远/近袖蒙版，放共享组，明确要求分别生成时遵从；头发按遮挡拆分；红衣主体完成后再追加前襟。独立RGBA不需先分割人物；伴素体分支则保留完整源图并按[配准/蒙版方法](references/sutai-registration-compositing.md)组装。
历史硬切回叠证据见[旧实验](references/foundation-conditioned-object.md)，不将其覆盖为最新默认步骤。生成光影或隐藏结构按实际状态标注，不将试验成功写成官设或完成图验收。
